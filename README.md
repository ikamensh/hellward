# Hellward 3D

[Hellward](../hellward/) in 3D: Tristram burns, the Fallen pour from a hell gate, and four kinds of tower hold
the lanes to the cathedral. One level, four monsters (Fallen, Fallen Shaman, Zombie, Skeleton) and four towers
(Arrow, Pyre, Frost Shrine, Storm Obelisk), built in **Godot 4.7** to see how far 3D can take the game.
[Why Godot](docs/engine.md).

## Play

```bash
brew install --cask godot        # once (Godot 4.7)
cd ~/saga/hellward3d
godot --path game                 # play
godot --path game -- demo         # watch a scripted defender play
godot --path game -- demo film    # the same, with a directed camera
```

| | |
|---|---|
| **1–4**, then click buildable ground | Arrow Tower, Pyre, Frost Shrine, Storm Obelisk (Shift keeps building) |
| click a tower | choose it: **U** upgrade, **S** sell, **C** cleanse a curse (35 mana) |
| **Space** | summon the next wave (early: a little gold) |
| **F** | double the pace |
| arrow keys / screen edges, wheel, middle drag | pan, zoom, turn the camera |
| right click / **Esc** | let go |

The Fallen Shaman is a leader: it stops, ponders (violet motes), then chants a violet beam at the tower hurting
its pack most. A rune circle closes round that tower's foot, and the curse halves the blows of every tower
inside it until it wears off or you Cleanse it.

The rules are the 2D game's Tristram (map, routes, waves, monster and tower numbers, exported by
`tools/export_level.py`), lightly simulated in GDScript. For the showcase the demo also offers the Pyre,
Frost and Storm towers that the campaign opens later, adds skeletons to the last waves, gives the Storm
Obelisk a forged coil's leap, and walks the monsters at 0.6 of the 2D pace so their legs stay believable.

## Make

Everything is generated by scripts in `tools/` (see [AGENTS.md](AGENTS.md)): models from Blender scripts,
textures and effect sprites from Codex paintings, sounds and music from the 2D game's audio code.
